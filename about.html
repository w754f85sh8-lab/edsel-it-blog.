About this website

This website is a personal blog created for an Information Technology for Managers course project.

Purpose

The site demonstrates how a simple information system can organize and publish digital content for a defined audience. It also shows the practical use of web technologies, responsive design, navigation, cloud hosting, and basic security principles.

Theme

The blog focuses on the intersection of business, technology, strategy, data analytics, process engineering, and digital transformation.

Technology used

  • HTML for structure
  • CSS for layout and design
  • JavaScript for simple interaction
  • Static web hosting for public access
The website intentionally uses a simple architecture so it is easy to understand, maintain, and present during class.
