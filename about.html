About the project

Engineering thinking with a business perspective.

This website is a personal blog created for an Information Technology for Managers course project.

Purpose

The site demonstrates how a simple web-based information system can organize and publish digital content for a defined audience while applying responsive design, navigation, hosting, and basic security concepts.

Theme

The blog focuses on business, technology, strategy, data analytics, process engineering, ERP, AI, and digital transformation.

Technology used

  • HTML for structure
  • CSS for design and responsiveness
  • SVG graphics for lightweight visual content
  • JavaScript for simple interaction
  • GitHub Pages for public hosting
The design intentionally balances visual quality with a simple architecture that is easy to explain during the class presentation.
